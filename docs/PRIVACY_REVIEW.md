# 개인정보 동의 문구 검토 자료

동의 화면에 나가는 문구는 `src/shared/constants/privacy.ts` 한 곳에 있습니다.
이 문서는 검토하시는 분이 문구와 실제 처리 방식을 맞춰 볼 수 있게 정리한 것입니다.
문구 버전: `2026-10-26`

## 1. 서비스 개요

- **처리자:** 서울지구 CCC 고3초청채플 운영진
- **행사:** 2026년 11월 26일(목), 신길교회(서울 영등포구 영등포로67가길 9)
- **대상:** 고3 참가자, 그리고 선배 역할을 하는 CCC 대학생
- **흐름:**
  1. **채플 등록 (모두):** 동의 → 이름·성별·연락처 → 고3/대학생 → 추천인·출신 고교(선택) 순서로 받습니다. 출석 교회는 묻지 않습니다.
  2. **멘토링 신청 (원하는 사람만):** 성향, 관심 분야, 학교·학과, 채플 도착 시간, 사진을 받습니다.
  3. **매칭:** 같은 성별끼리 묶습니다. 고3이 추천된 선배 중 한 명을 고르면 둘의 연락처가 서로에게 공개됩니다.
- **나이:** 만 14세 이상만 받는다고 동의 화면에 적었습니다. 나이 확인 절차는 따로 없습니다.

## 2. 동의 항목 (2개, 모두 필수, 각각 따로 체크)

**수집·이용 (제15조)**
- 목적: 등록과 당일 운영, 중복 등록 방지, 매칭, 안내 문자 발송
- 필수 항목:
  - 등록: 이름, 성별, 휴대전화번호, 구분
  - 멘토링: 성향, 관심 분야, 도착 시간, 학교, 학과·진로, 학번, 맡을 후배 수
- 선택 항목: MBTI, 사진, 초대해 준 사람, 출신 고교
- 보유 기간: 행사 후 90일(2027년 2월 24일)까지
- 함께 고지: 처리 위탁(Vercel·Supabase), 열람·정정·삭제 권리

**제3자 제공 (제17조)**
- 제공받는 사람: 매칭된 상대
- 목적: 멘토링 연락과 일정 조율
- 항목: 역할별로 따로 적었습니다. 고3이 올린 사진은 연결된 선배에게도 보입니다(2026-10-26).
- 보유 기간: 멘토링이 끝날 때까지

두 항목 모두 거부할 권리와, 거부하면 등록할 수 없다는 불이익을 적었습니다.

## 3. 검토가 필요한 지점

1. **민감정보.** 출석 교회는 종교를 드러낼 수 있어 2026-10-26부터 묻지 않습니다. 그 전에 받은 값은 DB에 남아 있고, 보유 기간이 지나면 다른 정보와 함께 파기됩니다.
2. **필수 동의 2개를 거부하면 등록이 안 되는 구조.** 이것이 "필요 최소한"에 맞는지 봐 주세요.
   - 특히 제3자 제공 동의는 등록 단계에서 받지만, 실제 제공은 멘토링을 신청한 사람에게만 일어납니다.
   - 대안은 제3자 제공 동의를 멘토링 신청 단계로 옮기는 것입니다.
3. **국외 이전.** Vercel과 Supabase는 미국 회사지만, 웹 서버(Vercel icn1)와 데이터베이스(Supabase) 모두 서울 지역에 있습니다(운영진 확인, 2026-10-26). 국외 이전에 해당하지 않는다고 보고 처리 위탁으로만 고지했습니다.
4. **개인정보 처리방침.** 별도의 처리방침 페이지는 없습니다. 동의 화면의 내용이 전부입니다. 공개 처리방침이 필요한 규모인지 판단해 주세요.
5. **문의처.** 동의 화면에 적힌 문의처는 "고3초청채플 운영진"뿐입니다. 실제로 연락이 닿는 번호나 이메일을 적는 것이 좋습니다(`CONTACT_FOR_PRIVACY`).
6. **나이.** 만 14세 미만을 걸러내는 절차가 없습니다. 고3 대상이라 해당자가 드물다고 보고 문구로만 알립니다.

## 4. 실제 처리 방식 (문구와 맞는지 확인용)

- **동의 기록:** 등록 행마다 동의 시각과 문구 버전이 저장됩니다. 동의가 없으면 DB가 저장을 거부합니다.
- **연락처 공개 시점:** 후보 단계에서는 010-****-5678처럼 가립니다. 고3이 선배를 고른 뒤에만 서로에게 보입니다.
- **운영자 화면:** 비밀번호로 접근합니다.
  - 운영자용과 보기 전용 비밀번호가 따로 있습니다.
  - 보기 전용도 연락처 전체를 봅니다.
- **파기:** 보유 기간이 지나면 운영진이 직접 실행합니다. 자동으로 파기되지 않습니다.
  ```
  npm run purge -- --event-end 2026-11-26 --yes
  ```
- **서버 로그:** 이름과 연락처는 남기지 않고 참여코드만 남깁니다.
